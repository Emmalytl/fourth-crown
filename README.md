# FOURTH CROWN — FCC-001 — Build 06

Build 06 keeps the approved Dribbble-inspired restaurant template while correcting the customer-facing visual and interaction issues reported during testing.

## Build 06 corrections
- Single add-to-cart confirmation popup with automatic dismissal.
- Floating cart is hidden while the confirmation popup is visible, preventing two cart notices from appearing together.
- Larger, more readable “What are you craving for?” content.
- Ingredient chips show the main ingredients used for each featured Ghanaian dish.
- Auto-advancing food carousel added immediately after the craving/ingredients introduction.
- Featured food cards are now equal in size; the jollof card no longer dominates the grid.
- Menu image URLs were migrated to new food references and old localStorage image values are overwritten for built-in demo items.
- Gari Fortor uses a gari-based dish reference rather than an unrelated rice image.
- Approved FOURTH CROWN transparent logo is retained and made more visible/responsive across header, hero and footer.
- Responsive layouts updated for desktop, tablet and mobile.

## Prototype status
This is still a frontend prototype. Authentication, database, payments, delivery operations and secure admin persistence are not production-connected yet.

Food photography in this prototype is referenced from external web sources for visual testing. Commercial launch should replace those images with restaurant-owned or properly licensed photography.

## Build 08 customer-facing updates
- Added mobile bottom navigation for Home, Menu, and Cart.
- Added floating Back to Top control independent of the footer.
- Removed the Admin entry from the customer-facing experience.
- Added contact number 850 465 6422 and an event-catering section.
- Added local service-carousel artwork so the caterer/pickup/delivery slides remain visible even if remote image hosts fail.
- Updated the FOURTH CROWN logo asset to include its warm background while keeping only the designed wordmark and steam mark.
- Removed the "Fresh herbs" ingredient chip.
- Reworked the palette to use cream, charcoal, terracotta, sage, and muted copper instead of the previous yellow-heavy treatment.


## Build 09 image sources
The service carousel now uses real photographic images from free-to-use Pexels sources for the prototype: a chef/waiter serving food, a restaurant pickup handoff, and a doorstep delivery handoff. Verify current licensing/usage terms before commercial launch and replace with FOURTH CROWN-owned photography when available.
